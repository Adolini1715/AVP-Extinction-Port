# Security

## Reporting a problem

Please report security problems privately: use **Security > Report a vulnerability** on this
repository (GitHub private vulnerability reporting), not a public issue. Include what you found,
how to reproduce it, and the build you used.

## What to know as a player

- **There are no official prebuilt downloads of the game.** The port is built from your own copy
  with `Install.bat`. Anyone offering a ready-made `avpe.exe` is not this project; do not run it.
- The only official sources are this repository and its Releases page.
- The installer downloads only pinned build tools, each checked against a SHA-256 before use.
- Save files from other people are data the game's 2003 loaders trust; treat them like mods.
- Session recordings stay in the game folder and are only sent if you send them.
