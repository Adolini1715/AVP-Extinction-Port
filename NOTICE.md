# What the licence covers

The MIT licence in `LICENSE` covers the code, tools, documentation and artwork written for this
port, with these exceptions:

- **The decompilation** is not in this repository: the installer fetches
  [AVP-Extinction-Decomp](https://github.com/Adolini1715/AVP-Extinction-Decomp), which has its own
  `NOTICE.md` (its reconstructed game code carries no licence).
- **`xboxrecomp/`**: a fork of [xboxrecomp](https://github.com/sp00nznet/xboxrecomp), MIT-licensed
  by its authors (see `xboxrecomp/LICENSE` and `xboxrecomp/LICENSES`).
- **`pc/hd/`**: redrawn letters for the game's font pages; the rest of each page is filled in from
  the player's own disc when the game runs.

No game data (art, audio, video, levels) is in this repository. Building the port needs your own
copy of Aliens versus Predator: Extinction.
